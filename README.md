# Контент-бот AMU Logistics

Бот сам ведёт Telegram-канал и Instagram компании: выбирает тему, пишет пост на русском и каракалпакском,
рисует картинку, карусель или рилс в фирменном стиле, присылает вам черновик и публикует.
Раз в неделю смотрит статистику и сам улучшает стратегию: частоту, часы, форматы, темы и стиль.

Работает на GitHub Actions (бесплатно, запуск каждые 15 минут). Пишет Claude по вашей подписке Pro.
Запасной ИИ — бесплатный Google Gemini: включается сам, если у Claude кончился лимит.
Ваш компьютер для этого включать не нужно.

## Как он работает

1. За 2 часа до удачного времени публикации бот выбирает тип поста (вопрос о растаможке, новый закон,
   совет, интересный факт, новость, услуга компании, праздник) и формат (фото, карусель, рилс).
2. Ищет свежие новости (kun.uz, gazeta.uz, daryo.uz, spot.uz + поиск Google) и законы, выбирает тему,
   которой ещё не было, и пишет текст. Цифры и номера законов — только из найденных источников.
3. Присылает вам в Telegram черновик с кнопками:
   **Опубликовать сейчас · Изменить текст · Другая тема · Другой формат · Отклонить**.
   Чтобы поправить текст, ответьте на черновик своими словами, например: «короче и добавь про сроки».
4. Если вы не ответили за 2 часа, бот публикует пост сам в Telegram-канал и Instagram.
5. Каждый день собирает статистику: охват, лайки, сохранения и репосты в Instagram, реакции в Telegram.
   Раз в неделю анализирует её, меняет стратегию и присылает вам отчёт: что поменял и почему.

## Что нужно один раз настроить (≈ 40 минут)

### 1. Токен Claude (подписка Pro)

Подписка Pro не даёт API-ключа, зато Claude Code выдаёт токен подписки на 1 год.
В обычном Терминале выполните команду, войдите в браузере и скопируйте токен `sk-ant-oat…`.
Это `CLAUDE_CODE_OAUTH_TOKEN`.

```bash
claude setup-token
```

Бот тратит небольшую часть лимитов Pro: 2–10 запросов в день.

**Запасной ИИ (по желанию).** На [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
нажмите **Create API key**. Это `GEMINI_API_KEY`: он нужен, если лимит Claude закончится.

### 2. Telegram-бот для контента

Нужен **отдельный** бот. Бот из `logistics-site` работает через Netlify, и эти два бота друг другу мешали бы.

1. [@BotFather](https://t.me/BotFather) → `/newbot` → имя `AMU Content`, username например `amu_content_bot`.
   Токен — это `TG_BOT_TOKEN`.
2. Откройте своего нового бота и нажмите **Start**. Без этого бот не сможет писать вам.
3. Канал @amulogistics → Управление каналом → Администраторы → Добавить → ваш бот.
   Включите право «Публикация сообщений».
4. Напишите [@userinfobot](https://t.me/userinfobot). Число, которое он пришлёт, — это `TG_ADMIN_ID`.
   Черновики приходят только этому человеку, и только его команды бот выполняет.

### 3. Instagram

Публиковать через API можно только из **профессионального** аккаунта, привязанного к странице Facebook.

1. Instagram → Настройки → Тип аккаунта → **Переключиться на профессиональный → Бизнес**.
2. Привяжите Instagram к странице Facebook: Instagram → Настройки → Центр аккаунтов.
   Если страницы нет, создайте её на facebook.com/pages/create.
3. [developers.facebook.com](https://developers.facebook.com/apps) → **Создать приложение** → тип «Бизнес».
   Проверка приложения не нужна: в режиме разработки оно может публиковать в ваш собственный аккаунт.
   В настройках приложения скопируйте **App ID** и **App Secret**.
4. Откройте [Graph API Explorer](https://developers.facebook.com/tools/explorer/) и выберите своё приложение.
   Добавьте разрешения `instagram_basic`, `instagram_content_publish`, `instagram_manage_insights`,
   `pages_show_list`, `pages_read_engagement`, `business_management`.
   Нажмите **Generate Access Token** и разрешите доступ к странице.
5. Короткий токен нужно превратить в бессрочный. В Терминале, в папке бота:

```bash
python3 tools/meta_token.py APP_ID APP_SECRET КОРОТКИЙ_ТОКЕН
```

   Скрипт выведет `IG_USER_ID` и `IG_ACCESS_TOKEN`. Этот токен не истекает.
   Если смените пароль Facebook, повторите шаги 4–5.

Instagram можно подключить позже: без этих ключей бот работает только с Telegram.

### 4. GitHub

1. Создайте аккаунт на [github.com](https://github.com).
2. **New repository** → имя `amu-content-bot` → **Public**.
   Публичный репозиторий даёт бесплатные и безлимитные запуски. Ключи хранятся в секретах, их никто не увидит.
3. Загрузите в репозиторий всё содержимое этой папки (кроме `.venv` и `out`).
   В Терминале (подставьте свой логин):

```bash
cd ~/Desktop/ИИ-монтажер/amu-content-bot && git init -b main && git add . && git commit -m "content bot" && git remote add origin https://github.com/ЛОГИН/amu-content-bot.git && git push -u origin main
```

4. Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**. Добавьте:

| Секрет | Значение |
|---|---|
| `CLAUDE_CODE_OAUTH_TOKEN` | токен из `claude setup-token` |
| `GEMINI_API_KEY` | необязательно: запасной ИИ |
| `TG_BOT_TOKEN` | токен контент-бота |
| `TG_ADMIN_ID` | ваш ID из @userinfobot |
| `TG_CHANNEL` | `@amulogistics` |
| `IG_USER_ID` | из `meta_token.py` |
| `IG_ACCESS_TOKEN` | из `meta_token.py` |

5. **Actions** → включите workflows → **content-bot → Run workflow**. Через минуту ветка `gh-pages` появится.
6. **Settings → Pages** → Source: **Deploy from a branch** → `gh-pages` / `(root)` → Save.
   Через эту страницу Instagram скачивает картинки и видео. Без неё Instagram не заработает.
7. Проверка: напишите контент-боту `/now`. Через 2–15 минут придёт черновик.

## Команды для бота

| Команда | Что делает |
|---|---|
| `/status` | что происходит, когда следующий пост |
| `/now` | черновик прямо сейчас |
| `/now рилс про сроки ЖД` | черновик в нужном формате (фото / карусель / рилс) и на нужную тему |
| `/redo` или `/redo больше про ЖД` | переделать текущий черновик с нуля: тот же тип и формат, новый текст и картинки |
| `/pause`, `/resume` | остановить / продолжить публикации |
| `/freq 5` | постов в неделю |
| `/hours 9 13 19` | часы публикаций (Ташкент) |
| `/rule текст` | постоянное правило. Например: `/rule не писать про авиадоставку`, `/rule в каждом посте упоминать склад в Иу` |
| `/rules`, `/unrule 2` | список правил, удалить правило |
| `/strategy` | текущая стратегия, которую бот выработал |
| `/learn` | проанализировать статистику и улучшить стратегию сейчас |

Бот отвечает в течение 15 минут: GitHub запускает его по расписанию, а не держит включённым постоянно.

## Перенастройка

- **`config/brand.yaml`** — описание компании, контакты (основной номер `phone`, второй `phone_uz`), языки, тон и правила с учётом менталитета, типы постов,
  праздники, источники новостей, режим модерации (`approval_mode`) и время на ответ.
  Менять можно прямо на github.com: откройте файл → карандаш → Commit.
- **`data/strategy.json`** — частота, часы, доли форматов и тем, выводы. Это бот меняет сам.
  Ваши правила (`/rule`) он не трогает никогда.
- **`assets/photos/`** — фото для обложек (сейчас 28 фото с сайта). Можно добавлять свои `.jpg`.
  Слово в имени файла — это тег: `truck-…`, `container-…`, `warehouse-…`, `night-…`.
- **`assets/music/`** — музыка для рилс (`.mp3`). Кладите только треки, на которые у вас есть права,
  например из бесплатной библиотеки YouTube Audio Library. Без музыки рилс выходят без звука.
- **`bot/templates/slide.html`** — дизайн карточек.

## Качество каракалпакского

Claude пишет на каракалпакском лучше Gemini, но всё равно читайте черновики. Если ошибок много,
оставьте на картинках только русский: `card_languages: [ru]` в `brand.yaml`.
Токен Claude действует 1 год: потом снова выполните `claude setup-token` и обновите секрет.

## Ограничения

- GitHub иногда запускает расписание с опозданием на 5–30 минут. Для постов это не критично.
- Telegram не даёт ботам статистику просмотров канала. Бот учитывает реакции, а главные цифры берёт из Instagram.
- Если лимит Claude Pro исчерпан, а ключа Gemini нет, бот пропустит пост и сообщит вам.
- Новые законы и цифры бот берёт из поиска. Перед публикацией такие посты помечены «⚠️ проверьте цифры».
